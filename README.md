# SAOS Classroom Operating System

The Structured Autonomy Operating System (SAOS) is a mastery-based instructional architecture designed to reduce teacher overfunctioning while increasing student ownership of pacing, struggle, and evidence-based reasoning.

---

## Core Design Question

How do we design a classroom operating system that:
- Reduces teacher overfunctioning
- Maintains integrity in the age of AI
- Protects DOK 3 reasoning depth
- Distributes cognitive load
- Sustains itself at 100+ students per day?

SAOS is the answer.

---

# Core Protocols

## 1. Evidence-Based Progression
- Task 1: Learning Through Struggle
- Task 2: Mastery Exit
- No skipping levels
- DOK 3 requires Pit Stop defense

## 2. Integrity Enforcement
- Weekly Snapshot Audit
- Backward movement if skipping detected
- Grade repair separate from pacing

## 3. Learner-Managed Pacing
- Visual Progress Tracker
- Queen pacing boundary
- Movement only after Exit

## 4. The Climb Rule
Before teacher help:
1. Review Mission File
2. Ask same level peer
3. Ask one level above
4. Then teacher

Documentation required.

## 5. Pit Stop (DOK 3 Defense)
- Written CER required
- Verbal defense required
- Revision if reasoning gaps appear

# Calibration System

When strain appears, categorize it:

- Pacing Breakdown
- Integrity Breakdown
- Climb Breakdown
- Collaboration Breakdown
- Depth Breakdown
- Teacher Overfunctioning Drift

Adjust the system.
Never add more slides.
